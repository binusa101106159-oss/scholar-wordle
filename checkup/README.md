# 健檢報告生成系統 beta v0.1

入口：主網站「健檢報告」，網址 `/#checkup`。

依已核定參考值與罐頭產生抽血、尿液、體位、血壓與 PE 草稿。原始資料與草稿只放在頁面記憶體，切換功能分頁、重新整理、關閉時清除，不寫入網站同步或本機儲存。

## 使用

貼入「欄名＋Tab＋結果」、`欄名：結果` 或 JSON 欄位清單，按「生成報告」。生成後來源鎖定，報告可手改；右側罐頭插入報告游標位置。按「清除並重新貼上」可開始下一份。

```text
性別：男
GLU AC：126
HbA1c：6.5
Ketone(Dipstick)：3+
```

TSV 可另帶單位與 H／L，例如 `GLU AC\t126\tmg/dL\tH`。JSON 可使用 `{"fields":[{"name":"GLU AC","value":"126","unit":"mg/dL"}]}`。實際完整醫院 Ctrl+A 內容仍待樣本驗證；未辨識行會提示。

## 本版已接入

- 有異常即列出，同類合併；腎臟與尿液分開，B肝獨立，體位與腰圍合併。
- HOMA只採來源值，取一位後分級，正常保留長版，不自行重算。
- 血壓嚴格採 `SBP >130` 或 `DBP >80`；BMI取一位後≥24寫體重過重。
- 血糖100／126、HbA1c 5.7／6.5界值，兩者依較高分類，單項達糖尿病門檻保留複檢確認。
- 血脂距正常界值<10每年，≥10三個月，TG>500儘速；不同項目的期限各自保留。
- 尿液23欄規則、Protein ±正常、尿酮3+且血糖正常亦可套空腹罐頭；試紙與定量不互換。
- 菌尿、白血球酯酶、Nitrite任一異常走疑感染分支，敘述只保留實際成立的異常。
- Dilute依試紙明確註記，不從歷史錯句推定；定量UACR獨立判讀。
- PE異常照實列出；B肝、糖尿病、甲狀腺有對應病史時改原醫師追蹤。
- AFP依性別及已知孕況分流；孕況不明保留條件句。
- CXR只在完整報告符合核定正常字典時省略；其他保留原文人工處理，脊椎相關提供復健科罐頭。

Mentzer index僅在Hb低、MCV低、有有效RBC時作疑似病因選句：<13疑地中海型、>13疑缺鐵、=13人工判斷；不是確診。參考原始研究：https://pmc.ncbi.nlm.nih.gov/articles/PMC9121960/ 。血糖界值：https://diabetes.org/about-diabetes/diagnosis 。

## 本版限制

心電圖、超音波保留原文並提示待LLM翻譯，尚未串接模型。肺功能由人工輸入，三者不重算數字。甲狀腺明顯異常的急迫性提示人工確認，未設未核定的硬切點。

特殊作業可複選與選檢查性質，本版管理級數由醫師逐項核定後帶入，尚未接入精簡版自動判級；不讀取一般健檢1／2A／2B或來源特作級數當新判定。噪音另用獨立系統，生物不判級。適性需醫師明確勾選才寫「可以從事XXX作業。」。

抽血完整性需使用者確認；尿液完整性會檢查23欄。缺項與未知結果不宣告整體正常。875筆歷史重播是開發驗證，非獨立臨床正確率驗證；新案例驗收仍待進行。

公開檔只包含程式、核定規則、通用罐頭與正常CXR字典。個案、原始歷史報告、trash data、個人資料均不在此模組。trash data不參與選句、科別、期限或慣用寫法統計。
