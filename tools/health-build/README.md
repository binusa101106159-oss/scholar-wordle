# 特做內容匯入

獨立資料位於 `health/`，不修改 `guides/`、其轉換器或資料。
使用既有指引轉換器的讀取函式；所有特做專用設定僅在本工具的模組實例中生效。
閱讀器沿用指引的操作方式，使用獨立 hx 前綴與本機儲存空間。

## 重建與核對

```powershell
$env:HEALTH_SRC='含兩份PDF的資料夾'
python tools/health-build/build.py
python -m http.server 8765
# 另一個終端機
python tools/health-build/review.py
$testFiles=(Get-ChildItem tests/*.cjs).FullName
node --test $testFiles
```

build.py 的章節切片只存 .local/health-source，不發布PDF。
每份內容均須印出OK；report.json記錄略去的頁碼、重複跨頁表頭、圖中可見文字與來源頁碼。
正文每個區塊的 pdf_page/pdf_last/source 可定位回來源，滑鼠懸停亦可查看。
review.py核對每個區塊的實際DOM文字，逐一開啟所有表格入口，檢查彈窗文字，產生每頁對照圖。
JSON保留原生列、欄及合併儲存格。首頁的裝飾題框以已視讀的原題文字取代，不當成表格；不發布章節頁面影像。

目前187張原生表格（完整版89、簡明版98，含巢狀表格）；第二批新增27張（完整版11、簡明版16），涵蓋95頁，無新增圖片。噪音原書的兩幅圖保留影像：
完整版PDF第35頁的純音聽力檢查流程、PDF第38頁的聽力圖比較。
聽力圖完整保留含直排座標標籤，避免文字被另行拆散；正文、圖說及表格仍可複製。
來源中疑似異常但未改正的例子：高溫分級表的蛋白尿門檻100 mg/dL、
噪音聽力檢查流程圖的「-1」、簡明版異常氣壓「管理分級建議詢問」標題。
這些是原PDF內容，不代表已查證其醫學或法規正確性。

## 指定章節與分開暫存

指定 ids 時，只更新所選內容，保留輸出目錄中其餘章節及報告紀錄。未指定 ids 則重建整個已編目範圍。
使用獨立暫存目錄前，先複製既有 health/ 與 report.json 到對應位置；核對原有檔案雜湊後才安裝新輸出。

```powershell
python tools/health-build/build.py full09 brief09 full10 brief10 full11 brief11 full12 brief12 --output .local/health-third/stage/health --report .local/health-third/stage/report.json
python tools/health-build/review.py full09 brief09 full10 brief10 full11 brief11 full12 brief12
```
