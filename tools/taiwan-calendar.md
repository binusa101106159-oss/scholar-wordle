# 月曆假日與回診資料

假日依[人事總處政府行政機關辦公日曆表](https://data.gov.tw/dataset/14718)的官方CSV，範圍2023–2027，共1826日。2025採114年10月20日修正版；來源網址、原檔SHA-256及每年筆數記在calculator/taiwan-calendar.json的sources。

原始「是否放假」0為上班、2為放假。只儲存與週末規則不同或有備註的106筆例外，涵蓋國定假日、補假、調整放假、補行上班，非自行推算農曆或假日。每筆日期及星期都核對來源。未涵蓋年份僅顯示週末，日期詳情提示尚無官方假日資料。

## 重建

將JSON sources中的官方CSV下載為2023.csv至2027.csv，放在同一資料夾，再執行：

```sh
python tools/build-taiwan-calendar.py <CSV資料夾>
```

UTF-8 BOM及CP950自動辨識，檢查整年連續日期、星期、放假值與筆數。沒有人工修改假日JSON。

## 回診標記

僅在登入狀態讀取既有ScholarStorage中的scholar-cases-v1。原始個案仍由既有私人Firestore同步；不新增個案公開檔案或額外對外傳送個資。相同日期的個案以藍點及筆數標示，點日期可看姓名、可點擊複製的病歷號、VS及原始回診時間。姓名與其他文字均以textContent呈現。

followupDate接受完整西元日期（2026/11/18、2026-11-18、2026年11月18日）及三位數民國年（115/11/18、民國115年11月18日），可保留上午、下午與時刻等後綴。缺年、不存在的日期或包含取消／改期／其他日期的字串不自行猜測，畫面提示確認日期；不改寫個案原始欄位。

收到個案同步變更後更新標記及日期詳情；登出立即清除個案標記、姓名與病歷號。假日資料載入失敗不影響捲動或計算機，並顯示載入失敗提示。

## 驗證

Node覆蓋官方國定假日、補假、補班、年份涵蓋範圍與日期解析。瀏覽器以虛構資料驗證三種引擎、1440/390/320px的藍點、同日多筆、民國年、文字安全、MRN前導零複製、遠端修改及登出清除；另保留連續日期、跨月、星期對齊、捲動、背景同步與計算機回歸檢查。
