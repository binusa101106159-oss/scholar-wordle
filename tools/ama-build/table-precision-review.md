# AMA 表格精度核對

來源為使用者提供的完整版 AMA Guides Sixth Edition，659 頁。此次範圍從第 1 章開始，涵蓋全部已上線的第 1–14、17 章：422 個原書實體頁面、420 個閱讀區塊、158 張編號表格，另含圖形、表單及問卷，共 186 個附件。第 15、16 章仍待匯入。

## 修正

- 原生 HTML 表格按來源實體欄寬、列高及合併格排列；各字元保留 PDF 原始座標，不再把間隔數字擠成一串。標題、附註、空白格及換行保留來源位置。
- 保留 Table 17-10（原書第 582 頁）的上方裝飾區、置中比例、A–E、數字及箭頭位置。
- 左右續頁保留兩側原始欄寬、格線與原生欄位；上下續頁維持原書重複表頭。
- 共用的原始格線只繪製一次，避免在每格重複整頁向量。彈窗不再單獨限制表格格線的高度，避免格線縮小而文字留在原位置。
- 原文文字維持可選取、可複製，深色表格不加入頁面截圖或 PDF。字形採瀏覽器替代字型，無逐像素相同的字型承諾。

## 原書數值

第 570 頁 Table 17-4 第一項 Class 1 原書確實印為四個數字「1 2 3 3」，已放大核對 PDF 字形與字元座標。第 564 頁 Table 17-2 對應位置則是五個數字「1 1 2 3 3」。兩者依原書分別保留，不補入原書沒有的數字。
