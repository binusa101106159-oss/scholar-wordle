# 視野圖片疊合工具（2026-11-23）

Figure 12-10（Goldman）及 Figure 12-11（Humphrey）彈窗提供「圖片疊合」。選擇本機圖片後，可分別拖曳、縮放、旋轉圖片或格線，調整格線透明度，並下載合併 PNG。另支援方向鍵細調、Shift 加速、重設位置及移除圖片。

Humphrey 支援 10-2、30-2、60-4 各左右眼及完整原圖。單眼格線使用原 SVG 的 viewBox 範圍，保留來源數值及圖形，不重算點位。此工具只進行手動對齊，不自動計算視野分數。

PNG、JPEG、WebP、GIF、BMP 在瀏覽器內解碼，限制 20 MB／5,000 萬像素；沒有上傳、雲端同步或持久儲存。讀取後釋放物件 URL，移除圖片後禁用下載。

`tools/field-overlay-browser.py` 用合成測試圖片驗證 Chromium、Firefox、WebKit 的 1440／390px：兩種工具各自完成上傳、獨立圖層設定、七種 Humphrey 視圖選擇、拖曳、鍵盤、透明度、PNG 下載、重設、移除及返回原圖，12 組皆通過。下載檔亦實際解碼檢查像素與尺寸。另有既有 311 項回歸測試通過。來源章節資料未改動，不需重建壓縮 AMA 資料。
