# AMA 原文轉換

這是獨立的 AMA 轉換器；不修改法規、指引、遊戲或其轉換器。

## 來源與範圍

使用使用者提供的完整版 `AMA Guides to the Evaluation of Permanent Impairment, 6e.pdf`。目前支援 c01–c14、c16–c17，原書第 1–99、101–127、129–319、321–345、347–382 頁，另含第 493–601 頁，共 486 頁，對應完整版 PDF 第 26–124、126–152、154–344、346–370、372–407、518–626 頁。來源共 659 頁。`AMA_SRC` 可指定完整版 PDF 的絕對路徑；預設為 `A:\職醫\AMA\AMA Guides to the Evaluation of Permanent Impairment, 6e.pdf`。

```powershell
$env:AMA_SRC = 'A:\職醫\AMA\AMA Guides to the Evaluation of Permanent Impairment, 6e.pdf'
python tools/ama-build/build.py c12 c13 c14 --audit .local/ama1214/audit.json
python -m http.server 8765
# 另一個終端機，使用同一 Python 環境與 Playwright 瀏覽器設定：
python tools/ama-build/review.py c12 c13 c14 --images --output .local/ama1214/review
```

需要 Python 3.11+、PyMuPDF、Pillow、Playwright 及其 Chromium。上述影像比較與完整稽核寫入 `.local/ama1214/`，不放入網站。第 1–3 章的既有紀錄保留於 `.local/ama-part1/`。只建置指定章節，其他已匯入 JSON 不重寫；引用目標則讀取所有已匯入章節。網站只讀取 `ama/index.json`、各章 JSON，以及 AMA 自己的 JS/CSS。

## 原文與版面

- 所有正文、圖說、表格欄位、附註、參考文獻與圖內文字，都取自 PDF 的原始文字座標，不以人工重打或翻譯補字。
- 版面註記只記錄原書頁碼、物件範圍與物件類型，不含正文或表格數值。PDF 的 cropbox 與 mediabox 不同；本轉換器一致使用裁切後座標。
- 每個保留字元恰有一個歸屬物件；輸出後另做 HTML 文字回讀檢查。忽略版面空白後，每頁字元總數與字元頻次必須相同。每個表格儲存格另核對字元順序與跨列、跨欄。
- 跑馬頁首、書名頁眉、頁碼與書邊章節標籤另列稽核；閱讀器提供原書頁碼。三張章首裝飾分隔線以原生水平線呈現。
- 省略三張章首重複的淡色裝飾徽記；Table 1-5 內的原始裝飾圖形保留為向量。
- 保留原文的行末連字號、拼字、數字、標點與上標，不做文字校訂。
- MathematicalPi 的編碼依 PDF 字型 Encoding/Differences 解碼；支援 β、α、μ、×、·、<、>、−、+、=、≥、≤、÷，以及無空白的 inline 編碼字典。WWDOC08 的 `c` 字形依來源轉成 ↑。未知字形或不可讀字元會中止建置。
- 表格為原生 HTML，保留空白格與合併格；Table 4-2 的非等距數值位置用原生文字座標保留，箭頭用 SVG 路徑；Table 4-3 保留全部 15 欄；兩張左右續頁總表依列接成 7 欄。Table 1-5 的填色表頭不視為跨列合併。Figure 2-3 報告表及 Appendix 3-1 問卷也使用原生欄位與表格。
- 真正的圖形使用原書向量路徑，圖內字仍可選取。水平或垂直線段的邊界面積為零，不能用面積交集判斷是否保留。沒有整頁影像或 PDF 嵌入。
- 正文改為單欄閱讀；採瀏覽器字型，空白填寫區和換行適應視窗，因此不承諾與印刷版逐像素相同。文字與表格數值不近似。

第 6–8 章的三張左右續頁總表在放大視窗依列接成 7 欄；正文保留實體頁片段與頁碼，以免第 6 章續表下方參考文獻移位。Table 8-2 的上下續表集中於同一放大視窗，保留印刷版重複表頭。兩張體重表保留 Height 跨列及 Weight 跨三欄表頭。

## 引用與閱讀功能

Table/Tables、Figure/Fig.、Appendix/Appendixes 的引用，只連到已匯入且確實存在的物件；複數引用分別連到各目標，也支援跨章。未匯入的 Appendix B 與 Combined Values Chart 保留原文，暫不加連結。

17 章維持原書順序；尚未匯入的章節顯示準備中。讀者可搜尋已匯入章節、跳轉小節、調整正文字級、標記文字並還原閱讀位置。所有狀態使用獨立的 AMA 本機儲存鍵。

## 驗證與發布

`review.py` 從實際瀏覽器 DOM 回讀指定章節的全部頁面（目前可驗證原書 486 頁），跨頁總表合併核對左右頁來源，逐格比對 PDF 來源、點開每一個圖表引用及放大按鈕，並測試 1400、390、320 px 的章節切換、鍵盤操作、搜尋、標記及閱讀位置還原。`--images` 會產生原書在左、重排後網站在右的逐頁比較圖，以及每個圖表的放大圖，須人工檢視。

發布前執行 `node --test` 的既有全站測試，確認 `laws/`、`guides/`、兩個既有轉換器、`index.html` 與遊戲沒有差異。AMA JS/CSS 改動須遞增 `sw.js` 的快取名稱。只提交 AMA 成品、獨立工具與快取版本；不提交來源 PDF、環境或比較影像。

詳細紀錄：[第 1–3 章](c01-c03-review.md)、[第 4–5 章](c04-c05-review.md)、[第 6–8 章](c06-c08-review.md)、[第 9–11 章](c09-c11-review.md)、[第 12–14 章](c12-c14-review.md)。

第 9–11 章新增 38 張表格。Table 9-14、10-15 的左右續頁總表在放大視窗接成 7 欄；Table 11-2 接成 56 欄，保留原書空白格及兩側均未印出的 315 列，不補數值。大矩陣可橫向捲動；Table 11-1、11-3 的欄名獨立成表頭列。白色填色覆蓋表格線的物件以座標格線重建，裝飾用 SVG 路徑，數值仍為原生文字。引用也支援 Table 10-2a/10-2b 與原書無空格的 SeeTable 文字。

第 12–14 章包含 48 張編號表格、11 個圖／表單，以及 BPRS 的 24 項症狀評分表。Table 12-6 的三組數值使用各自的欄位；Table 12-11 保留空白窄欄、合併標籤與每格上下兩個數值。BPRS 的續欄／續頁保留實體頁碼，表格範圍依原書橫線分段，不把下一小節包進格內。

第 315、317 頁的視野疊圖是 PDF 中原本的點陣圖形，僅這兩張原始圖形以嵌入 SVG 的圖片保留；不是頁面截圖。第 317 頁共有 109 個圖內文字標籤，放大核讀後由 raster_1214.py 記錄其文字及位置，改為可選取、可複製的 SVG 文字。原有格線與點保留，只移除原來的圖片文字，避免雙重顯示。圖內數字不是依公式重算；左右 8x／6x 差異也保留。新增字型解碼 ±、″、°、| 及另一組 =、+、× 編碼，均以原書放大字形確認。

第 17 章含原書 557–601 頁、15 張編號表格及 8 個圖／表單。頸椎、胸椎、腰椎續表在放大視窗合併；正文保留實體頁碼。評估紀錄表以原生 HTML 格子及可複製文字重建，選項框與圈選標記保留原始向量線條。Figure 17-A 的 15 題 PDQ 及刻度使用原生 HTML。Table／Figure 17-A 的字母編號引用也可連結。詳見 [第 17 章核對報告](c17-review.md)。

第 16 章含原書 493–556 頁、25 張編號表格、13 個圖／表單及附錄 16-A 問卷。6 組多頁續表在彈窗依來源順序接續；Table 16-10 的兩個同頁片段也保留正確先後。紀錄表的外層格子為原生 HTML，內部評分框及圈選為原始向量，文字按 PDF 字元座標排列。12 個原始圖片物件保留 PDF 的遮罩、裁切與繪製順序，避免重複顯示被遮住的圖形。第 546、548 頁兩張圖片中的 9 行標籤經原始像素核讀後轉為原生文字；不嵌入整頁截圖。另增加數學字型 A／B 解碼及頁尾排除稽核，保證第 16 章只排除書眉、頁碼與書邊章節標籤。第 15 章仍準備中。詳見 [第 16 章核對報告](c16-review.md)。

從第 1 章起的表格精度重檢：預設按 PDF 字元座標、原始欄寬與列高建立原生 HTML 表格，保留數字間距、置中、換行、合併格及空白格；表題與附註也使用來源位置。格線及箭頭只繪製一次，與文字維持相同縮放，避免長表格受到彈窗高度限制而錯位。左右續頁保留兩側實體欄寬與格線。所有文字仍可選取與複製；瀏覽器替代字型與印刷字型的字形不保證逐像素相同。詳見 [表格精度核對](table-precision-review.md)。
