# Figure 標題與複合表單修復（v213）

## 問題與處理

Figure 快覽之前刻意只輸出圖號與頁碼，沒有提取標題。本次為全部 69 個 Figure 建立來源標題，寫入壓縮章節的捷徑 metadata；桌面和手機直接顯示，不需預載每張圖。標題提取支援圖下方的標題、長標題、原生 SVG 圖題及兩頁疊圖，避免把 Hip 等圖內標籤當成標題。

Figure 15-13、15-31 的問題是把原始表單底圖、絕對定位欄位與一般表格依序堆疊，造成大空白、表格與欄線分離。從原書重建以下同類表單，讓圖面、欄位及儲存格使用同一座標系統，文字仍為可選取的 HTML，不是整頁截圖或 PDF 嵌入：

- 15-2（原書 388 頁）
- 15-13（462、463 頁，完整保留兩頁）
- 15-31（480 頁）
- 16-2（498 頁）
- 16-12（551 頁）
- 16-13（554 頁）
- 17-2（561 頁）
- 17-7（598 頁）

一般表格維持可重排的正常段落；這些圖內表單保留原書欄位與選項位置。兩個字母的 F／M、R／L 等選項各自保留原始定位，避免字距調整把文字移出原書圈選。原始臨床數值、字詞及圖形保留，不代改原書拼字。

## 驗證與保留資料

`repair_forms.py` 逐頁比對原輸出與重建結果的非空白字元頻次，全部一致。9 個來源頁面共 15,037 個非空白字元，在相同儲存格或來源錨點內皆能安全對位；版本 3 畫線轉移可銜接既有版本 1／2，讀取不覆寫原儲存紀錄，新畫線保留 legacy 紀錄。此數字不是宣稱空白字元位置完全相同。

201 項測試通過。`ama-forms-browser.py` 在 Chromium、Firefox、WebKit 各 1440／390 px，實際開啟全部 8 個表單，驗證標題只出現一次、兩頁續圖完整、表單高度不再堆疊、原生儲存格與圖面欄線同寬、文字正常，以及 Figure 15-31 的 F／M／R／L 對應原書圈選位置。加入發布流程。另重跑既有全範圍文字／引用、Figure 15-3 像素、頁碼與本章搜尋、快覽及彈窗動畫檢查。

目視核對 Figure 15-13 的開頭與續頁末段、15-31 的表頭與範例欄位，以及 16-13、17-7 的版面。沒有宣稱所有 69 個 Figure 都逐像素人工比對原書。重建工具與自動檢查保留供後續回歸；本機紀錄在 `.local/form-repair/`、`.local/ama-form-browser/`。
