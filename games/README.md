# 小遊戲（2026-11-25）

放在主選單「小遊戲 ▾」內，與 Wordle、Crossword、Sudoku 並列；共用一個面板 `#minigames-panel`，各有自己的網址：`#g2048`、`#mines`、`#iarcquiz`、`#lawmatch`、`#connect`。程式於第一次開啟時延遲載入（`games/logic.js` 規則、`games/minigames.js` 介面、`games/minigames.css`）。

| 遊戲 | 內容 |
|---|---|
| 2048 | 4×4，方向鍵／WASD 或滑動；記錄分數與最高分，盤面保留。 |
| 踩地雷 | 初級 9×9／10 雷、中級 16×16／40 雷；第一下及周圍 8 格必定安全；右鍵、長按或「插旗」模式插旗；點已開數字且旗數相符時開周圍格；記錄各難度最佳秒數。 |
| IARC 分級 | 由 `iarc/data.json`（本站 IARC 分頁的官方快照）出題，先隨機選分級再選該級物質，四級出題機率相同；作答後顯示評估年份與 Monograph 卷次。 |
| 法規條次 | 由「法規」分頁的 `laws/text/*.json` 條文出題。兩種題型：看條文選「《法規》第 N 條」，或看條次選條文。四個選項中一個為同一法規的其他條，其餘為其他法規；可選法規分級或全部。含表格／公式的條文、刪除條文、不足 20 字的條文不出題。 |
| 職醫 Connections | 16 項分 4 組，錯 4 次結束，「差一個」提示。題庫兩種：①指引分類＋法規附表：指引依 `guides/index.json` 的危害分類（人因、化學、物理、生物、預防計畫指引），名稱只去掉結尾「認定參考指引」與「(修訂版)」；法規附表依所屬法規（至少 4 個附表者）。②IARC 分級：Group 1／2A／2B／3。同時出現在兩個來源組的項目一律排除，所以每個項目只有一個正確分組。 |


## 條文填空、錯題本、每日一題（2026-11-25）

另外加入三個項目：`#lawcloze`、`#mistakes`、`#daily`。
- 條文填空：同法規條次的條文來源與排除規則。把條文中「數字＋單位」挖空，涵蓋期限、人數、比例、年齡、次數、距離等，例如三個月、二分之一、百分之五十、五十人。「一百十五年六月二十六日」這類日期不挖。另外三個選項是同一法規範圍內同單位的其他數值；可選法規分級。
- 錯題本：IARC 分級、法規條次、條文填空（含每日一題）答錯時自動收錄，重複答錯會累加次數，最多 300 題。練習時答對一次即移出；如果資料更新後找不到原題，該題會自動移除。可一鍵清空。
- 每日一題：每天三題，分別是 IARC 分級、法規條次（看條文選條次）、條文填空，法規題取自 S 級。以台北日期當種子，所有裝置同一天題目相同。作答後會保留，當天不能重答；三題都作答即完成當天，前一天也完成時連續天數才會接續，另記錄最佳連續天數。

- 所有題目與分組都直接取自本站既有資料，沒有另外撰寫醫學或法規內容。分組是本站資料的分類方式（例如指引的危害分類沿用職安署原列表），不代表其他分類方式錯誤。
- 戰績與 2048 盤面存在 `scholar-minigames-v1`（ScholarStorage；登入時隨帳號同步），不含任何病人資料。
- 驗證：`tests/minigames.test.cjs`（合併、地雷安全區、展開與連鎖、IARC 均衡出題、條文擷取與選項不重複、Connections 分組互斥、填空不挖日期且選項同單位、錯題本累加與移除、每日題目固定與連續天數跨月年）；`tools/minigames-browser.py`（選單 8 項、2048 鍵盤與滑動、踩地雷首擊安全／插旗／難度、IARC 與法規作答、兩種題型與分級切換、Connections 解一組再錯 4 次、1440／390 無水平溢出、條文填空作答後補回空格、IARC 答錯進錯題本並在錯題本練習、每日一題三題作答後重開仍保留且連續 1 天、回到 Sudoku 正常）。
