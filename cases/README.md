# 個案追蹤

七欄：姓名、病歷號、日期、目的、診斷、回診時間、備註。
新增／編輯需按儲存，刪除需再次確認。病歷號使用字串保留開頭的0。
日期預設裝置當天日期；回診時間為自由文字，可填日期、時段或尚未確定的安排。
桌機表格、手機卡片；搜尋涵蓋七個欄位，可用空格分開多個詞。

資料只寫入目前網站來源的瀏覽器 localStorage，key為 `scholar-cases-v1`，
格式為 `{version:1,records:[{id,name,mrn,date,purpose,diagnosis,followup,notes}]}`。
沒有遠端資料庫、上傳、跨裝置同步或備份功能；清除網站資料會刪除記錄。
部署只含介面程式，不包含使用者的記錄。

每次寫入前重新讀取儲存內容，避免覆蓋另一分頁新增的其他個案。
格式無法讀取時保留原值並暫停修改；寫入失敗保留原記錄與表單草稿。
使用者輸入透過textContent顯示，不解析為HTML。

驗證：`tests/cases.test.cjs`涵蓋欄位、前導0、壞資料、編輯及搜尋。
另以隔離瀏覽器的虛構資料測試CRUD、取消、重新載入、多分頁更新、
HTML注入字串、儲存失敗草稿保留，以及1440／390／320像素操作。
測試記錄與畫面留在.local，不發布測試資料。
