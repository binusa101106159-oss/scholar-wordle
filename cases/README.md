# 個案追蹤

七欄：姓名、病歷號、VS、回診目的、診斷、回診時間、備註。
新增／編輯需按儲存，刪除需確認。病歷號以字串保留開頭的0；回診日期保留自由文字，旁邊新增上午／下午選單。新增病人必須明確選擇時段，不預選。舊個案不自動推定或補寫時段，仍可讀取與編輯，待使用者自行補齊。桌機表格、手機卡片，搜尋涵蓋七欄。

Google登入後，以ScholarSync與Firestore儲存，每位病人為獨立且具revision的項目。只有已驗證的擁有者帳號可讀寫自己的資料。清單格式仍為version:1及records陣列，另有createdAt供排序。
資料只暫存在頁面記憶體，不寫入localStorage、公開GitHub或service-worker快取。未登入不能新增；儲存／刪除等待伺服器確認後才關閉視窗。

表單保留開啟時的基準，未修改欄位沿用其他裝置的新值；同一欄位衝突以最後成功提交為準。已在另一裝置刪除的個案，不會由過期表單重新建立。
寫入失敗保留草稿，明示未確認；未儲存草稿離開頁面會要求瀏覽器提示。輸入只以textContent顯示。依使用者決定，舊本機個案不自動上傳。

驗證：cases.test.cjs測試資料與搜尋；cloud-sync.test.cjs測試合併、分片、刪除、失敗與帳號隔離。隔離瀏覽器及模擬Firestore以虛構資料測試兩裝置CRUD、同病人不同欄位合併、拒絕儲存草稿保留、登出與1440／390／320版面。
真實Firebase SDK未登入啟動及鎖定個案介面已檢查；正式擁有者登入寫入與第二裝置讀回仍須由使用者帳號完成最後驗證。測試資料與畫面不發布。

回診時段以可選欄位 `followupPeriod` 儲存（AM／PM）；舊資料可缺少此欄位。新增時在表單與 upsert 皆檢查必填。編輯仍保留其他裝置的未修改欄位，包含時段。回診欄、搜尋及兩個行事曆詳情會顯示所選時段；大行事曆在對應上下午半格標示回診筆數。既有日期文字原樣儲存，只有顯示時以明確選擇的時段為準。

回診日期旁自動顯示星期（一至日），同時套用清單及兩個月曆的回診詳情。星期以已驗證的完整西元／民國日期計算，使用 UTC 日期避免時區偏移；不改寫儲存值。缺年、無效或取消／改期等不確定日期不推算星期。

回診日期可直接輸入西元 8 碼（如 `20261113`）或民國 7 碼（如 `1151113`），亦支援全形數字與原有分隔符號格式。表單即時預覽西元、民國及星期；清單與兩個月曆使用同一日期解析，連續數字顯示時補上斜線。原始輸入仍原樣儲存，舊個案不自動改寫。無效日期不產生星期或月曆回診標記。

每筆追蹤中的個案可按「結案」，雲端確認成功後移至 `Archive（結案）` 分頁。結案保留全部欄位，以可選布林欄位 `archived` 儲存；缺少欄位的舊個案視為追蹤中。Archive 可搜尋、編輯及恢復追蹤，結案個案不再出現在兩個月曆的回診標記與詳情。失敗時留在原分頁，不刪除資料；編輯欄位與跨裝置合併保留既有結案狀態。

## 母性保護回電

第三個 subtab 排在「追蹤中」「Archive（結案）」之後，用於書面審查時的員工電話確認。欄位包含姓名（必填）、員工編號、單位、案件編號、聯絡電話、狀態說明、轉介日期、審查期限、回電日期、初判等級（未定／第一級／第二級／第三級）、詢問事項、確認事項、進度（待回電／已回電／已報主治確核／已完成）、備註。編號與電話都是字串，保留開頭的 0。三種日期沿用西元 8 碼／民國 7 碼及分隔格式，預覽西元、民國與星期，原始輸入原樣儲存；空白回電日期表示尚未回電。審查期限在新增時預設轉介日期加 7 天，可手動修改，手動指定後不再隨轉介日期變動。

詢問及確認 textarea 一行一題，空白行忽略，每題存成 `{id,text,done,reply}`。文字相同的題目重排時保留原 ID、勾選及回覆，重複文字逐題配對。清單直接勾選、填回覆，再按每筆的「儲存回覆」；未確認寫入的草稿留在記憶體。若該筆尚有未儲存回覆，需先儲存再開編輯表單。完成進度顯示如「詢問 3/14、確認 1/3」。完成移至此 subtab 的「已完成」篩選，仍可編輯、搜尋、恢復待回電，不會刪除紀錄。清單先列未回電者，再按期限由近至遠；過期與剩 2 天內附文字及醒目標示，已完成不再顯示期限警示。搜尋涵蓋所有文字欄位、題目與回答。

獨立使用 `scholar-maternal-calls-v1`，格式 `{version:1,records:[...]}`；沿用 ScholarSync 擁有者驗證、`requireAccount()`、ScholarStorage `setConfirmed()` 與每筆紀錄的 revision 分片、Firestore transaction。表單與清單回覆保留編輯基準，未修改欄位及題目內的 done／reply 沿用遠端新值；相同欄位以最後成功提交為準，已刪除紀錄不由過期表單復活。伺服器回傳後讀取合併結果；儲存、刪除等待確認才關閉視窗，等待期間鎖定取消與 Escape，失敗保留草稿並明示未確認。

資料只在頁面記憶體及擁有者私人 Firestore，不寫 localStorage、不進公開 repo、不進 service-worker 快取。service worker 僅包含公開程式碼，Firestore 跨來源請求不攔截；不更動既有追蹤中／Archive 資料，也不接入兩個月曆。所有使用者文字以 textContent／表單 value 顯示。離開整個頁面會遺失未成功儲存的草稿，瀏覽器將提示；切換分頁保留記憶體草稿，登出清除私人資料。

驗證：`tests/maternal-calls.test.cjs` 涵蓋解析、題目轉換與保留、搜尋、排序、期限與合併；`tests/cloud-sync.test.cjs` 另測未登入、拒絕寫入、帳號切換。`tools/maternal-calls-browser.cjs` 使用隔離頁面與模擬 transaction，檢查兩裝置 CRUD、回覆合併、失敗保留、刪除防復活、純文字顯示，以及 1440／390／320 表格與卡片、表單溢出及標頭重疊。安裝 Playwright 後可執行 `node tools/maternal-calls-browser.cjs [截圖輸出目錄]`。所有測試員工資料均虛構，測試不接觸正式 Firebase；正式帳號登入及跨裝置讀回須由擁有者驗證。

## 母保罐頭

位於母性保護回電之後，沿用 ct-、sg-btn 與表單的靜態 JSON 資料驅動呈現。`cases/maternal-snippets.json` 的 `sections → groups → snippets` 收錄使用者提供的五區、58 則通用原文；情境標示只放 label，其餘文字、全形標點與【】佔位符原樣保留。此資料為提供文字的逐字匯入，不另行改寫內容。`tests/fixtures/maternal-snippets-source.txt` 保留原文供測試依序逐條比對 text 與 label，另檢查全部 text 串接一致及 ID 不重複。

左側依基本資料、工作內容、風險評估、工作建議、結尾分區，各組可收合，搜尋涵蓋所有片段文字。每張卡片可直接複製或加入右側組合區；經常／偶爾、站立／靜坐等選項可用小標籤切換，僅影響這次複製／加入的文字，不改靜態原文。組合區每則文字可直接編輯，可重複加入同一來源、以拖曳把手、上下方向鍵或上移／下移按鈕排序，並刪除單則或清空。

預覽依加入及調整後的順序組合，只對相鄰片段決定連接方式：同組以「；」連接，跨組以「。」連接；開頭原有「，」「：」直接銜接下一則，內文標點原樣保留，避免重複句尾標點，結尾補「。」（既有「。」「！」「？」不重複補句點）。預覽以底色標出尚未替換的【】（包含空白【】），全部複製前先提示確認。編輯後即時更新預覽；剪貼簿失敗會顯示錯誤，仍可手動選取預覽複製。

組合內容不會儲存，離開頁面即清除。組合文字及選項只存在頁面記憶體，完全不呼叫 ScholarStorage，不寫 localStorage，也不上傳雲端；離開此 subtab、切換網站 tab、登出／帳號變更或 pagehide 時清除，避免瀏覽器上一頁快取保留已填入的個案文字。service worker 只快取公開 JSON 與程式碼。桌機兩欄；手機組合區固定底部，可展開／收合，展開時內部捲動。未新增自訂罐頭功能，既有追蹤中與 Archive 資料格式不變。

驗證：`tests/maternal-snippets.test.cjs` 檢查原文、結構、唯一 ID、標點、佔位符、搜尋與詞語選項；`tools/maternal-snippets-browser.cjs` 檢查加入、編輯、複製確認、拖曳／鍵盤排序、離開清除、不呼叫儲存，以及 1440／390／320 版面。安裝 Playwright 後可執行 `node tools/maternal-snippets-browser.cjs [截圖輸出目錄]`，測試不連正式 Firebase。
