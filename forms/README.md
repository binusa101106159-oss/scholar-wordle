- PDQ第2題例子為「洗碗」，保留；沒有改成英文原文的washing或自行改為洗澡。
- PDQ第3題為「旅遊意願」、第4題「起立或坐下」，照中文掃描版，不以先前英文版本替換。
- PDQ第13題兩端標示「沒有影響／完全無法從事」，雖與詢問協助的句型不同，仍保留原樣。
- QuickDASH採使用者檔案中的「肩膊」「病癥」「餘閒活動」等文字，不替換成另一個臺灣版。
- 以上為逐頁視讀轉錄並核對，並非宣稱掃描來源具有可自動比對的文字層；六頁皆為影像，兩張空白背面確認為空白。未將掃描圖片或PDF嵌入網站。

## 操作

完整題目、原生radio大面積點選、清楚選取狀態、鍵盤與觸控支援；每份單獨重設，確認後才清除。QuickDASH允許一題遺漏並揭露題號，其餘需完整作答才產出病人結果。提交後提示交醫療人員確認。

未登入時依既有系統僅保留本次使用記憶體；登入後草稿透過既有ScholarStorage同步。尚未整合病人姓名或自動寫入個案紀錄，避免將問卷錯配到個案。
