# scholar-wordle
## 頁面縮放（2026-11-25）

手機與平板的導覽列最左邊有「A 100% A」縮放鈕（`zoom.js`、`zoom.css`），樣式與主分頁相同的玻璃膠囊。
- 段數與 Safari 相同：50、75、85、100、115、125、150、175、200%。點百分比回到 100%。
- 作法是改寫 viewport meta：版面寬度＝裝置寬度 ÷ 倍率，再以該倍率顯示，所以整頁重新排版；vh、innerHeight 與各種彈出選單位置都維持一致。原本關閉雙指縮放的設定不變。轉向時依新方向重算。
- 倍率只存在這台裝置（localStorage `scholar-zoom-v1`），不隨帳號同步。
- 桌機瀏覽器不採用 viewport meta，且已有 ⌘／Ctrl ＋／－，所以不顯示這個按鈕。曾試過以 CSS zoom 做桌機版，但 vh 版面與彈出選單（例如小遊戲選單）在 125% 時位置錯誤，所以沒有採用。
- 驗證：`tools/page-zoom-browser.py`（Chromium 模擬 iPhone 13、iPad：各段切換、版面寬度、選單位置、重新整理保留、回到 100%、上下限；桌機不顯示）。

## 自訂分頁（2026-11-26）

主導覽列最後一個分頁「自訂」（`#customize`；`customize.js`、`customize.css`）。
- 桌布：預設光暈、純黑、極光、夕陽、深海、森林、餘燼、石墨，或上傳自己的圖片。上傳的圖片會縮到長邊 2560 px 以內、轉成 JPEG，只存在這台裝置（localStorage `scholar-wallpaper-image`），不上傳也不同步；可調變暗 0–80% 與模糊 0–20 px。
- 強調色：8 種預設加自訂色。套用在目前分頁的玻璃鏡片、主要按鈕、核取／單選與滑桿、焦點外框、Connections 選取格。
- 主題色調：中性、藍、青綠、綠、紫、暖、玫瑰。為導覽列、分頁膠囊與共用玻璃變數加上淡淡色彩。導覽列維持原本的不透明度，避免拖慢捲動。
- 設定存在 `scholar-customize-v1`，登入時隨帳號同步。另在本機保留一份副本，讓頁面一開始就套用，不會先閃一下預設樣式。另一台裝置選了圖片桌布、但這台沒有那張圖時，暫時顯示預設光暈。
- 全部是預設值時，不會加上任何覆寫，網站外觀和原本完全相同。「全部恢復預設」可一鍵還原。
- 驗證：`tools/customize-browser.py`（Chromium 1440／390：分頁在主導覽列、各桌布、上傳只存本機且不進同步資料、變暗滑桿、強調色套到分頁鏡片、色調、重新整理後保留、切到其他分頁正常、恢復預設後與原本相同）。

## 法規條文：原文／阿拉伯數字切換（2026-11-26）

法規閱讀器工具列有「123 阿拉伯數字」開關（`laws/numerals.js`），只改畫面上的字。資料檔、搜尋索引、條文填空題，以及原文模式的畫線都不動。
- 轉換範圍：
  - 條次與項款：第六條第三項 → 第 6 條第 3 項；第十五條之一 → 第 15 條之 1。
  - 數量、期限、日期：三個月 → 3 個月；一百十五年六月二十六日 → 115 年 6 月 26 日。
  - 分數與比例：二分之一 → 1/2；百分之五十 → 50%。
  - 時刻：午後十時至翌晨六時 → 10:00PM 至翌晨 6:00AM；八時至十七時 → 8:00 至 17:00。
  - 大金額加千分位：150,000 元。
  - 數字前後依全國法規資料庫寫法加空格。
- 不轉換：
  - 款目編號「一、」「（一）」。
  - 附表名稱「附表一」，以及附表連結範圍內的文字。
  - 「一般」「一定」「之一」「臨時」「同時」「畸零」等詞語。
  - 表格與公式內的文字。
- 套用範圍：條文、章節標題與法規說明段。
- 畫線分開保存：阿拉伯數字模式的畫線存在 `<法規id>@arabic`，原文模式的畫線不受影響；切回哪個模式就顯示該模式的畫線。
- 開關狀態屬於閱讀設定（`scholar-reading-v1`），和字級、行距一樣隨帳號保存。
- 驗證：
  - `tests/law-numerals.test.cjs`：使用者給的例句、不轉換清單、日期、比例與時刻；全部 18,000 多行條文轉換後，附表連結仍對準原字。
  - `tools/law-numerals-browser.py`：勞工健康保護規則實際切換、附表連結可開、兩種模式畫線分開、設定有存。
